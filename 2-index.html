OS lab — all 12 experiments

Shell programs · Kali Linux · 12 files

Every experiment's full code in one place. Open an experiment, copy the code into a file named expN.sh, and run it in the lab.

Illustration, not a screenshot.

How to use this
  1. On the Kali machine, make a practice folder once: mkdir -p ~/os-lab-practice then cd ~/os-lab-practice.
  2. Open an experiment below, tap Copy, and paste it into a new file named expN.sh (for example exp1.sh). nano exp1.sh works.
  3. Run it with sh expN.sh (exception: Experiment 7 prints best with bash exp7.sh).
  4. Some experiments need test files in the same folder (names.txt, student.txt, demo.txt, notes.txt). The note under each sample output says what to create.
Heads up: All 12 programs were really run and tested. Experiment 7 is the only one that prefers bash - under sh it still works but prints a stray -e line. In Experiment 10, useradd, groupadd, apt and ssh need admin rights or a real server, so practise those only if your teacher allows.

Aim

To count characters and reverse a string.
exp1.sh
clear
echo "Enter a string"
read text
char=$(echo -n "$text" | wc -c)
echo "Number of characters = $char"
echo "Reverse:"
echo "$text" | rev

Aim

To count vowels in a string.
exp2.sh
clear
echo "Enter a string"
read st
count=0
for ch in `echo "$st" | fold -w1`
do
          case $ch in
                 [aeiouAEIOU]) count=`expr $count + 1` ;;
          esac
done
echo "Number of vowels = $count"

Aim

To generate prime numbers between two limits.
exp3.sh
clear
echo "Enter lower limit"
read l
echo "Enter upper limit"
read u
for n in `seq $l $u`
         do
         flag=0
         for i in `seq 2 \`expr $n - 1\``
         do
                  if [ `expr $n % $i` -eq 0 ]
                  then
                          flag=1
                  fi
         done
         if [ $flag -eq 0 -a $n -gt 1 ]
         then
                  echo $n
         fi
done

Aim

To find factorial of a number.
exp4.sh
clear
echo "Enter a number"
read n
fact=1
while [ $n -gt 0 ]
do
          fact=`expr $fact \* $n`
          n=`expr $n - 1`
done
echo "Factorial is $fact"

Aim

To write a menu-driven program for common Linux commands.
exp6.sh
clear
echo "MENU"
echo "1. rm -r (Remove directory)"
echo "2. uniq (Remove duplicate lines)"
echo "3. tail (Display last lines)"
echo "4. cmp (Compare two files)"
echo "Enter your choice"
read ch
case $ch in
        1)
                echo "Enter directory name to remove"
                read dir
                rm -r "$dir"
                echo "Directory removed"
                ;;
        2)
                echo "Enter file name"
                read f
                uniq "$f"
                ;;
        3)
                echo "Enter file name"
                read f
                tail "$f"
                ;;
        4)
            echo "Enter first file name"
            read f1
            echo "Enter second file name"
            read f2
            cmp "$f1" "$f2"
            ;;
       *)
            echo "Invalid choice"
            ;;
esac

Aim

To compress and decompress a file using gzip and gunzip.
exp7.sh
clear
echo "File creation"
echo "Enter the name of the file to be created"
read filename
echo "Enter the content for the file"
cat >> "$filename"
echo "The size of the file before compression"
ls -l $filename
gzip $filename
echo -e "\nResult of compression"
ls -l $filename.gz
gzip -l $filename.gz
echo "Decompressing the file"
gunzip $filename.gz
echo "The size of the file after decompression"
ls -l $filename

Aim

To change file permissions using chmod.
exp9.sh
clear
ch=y
while [ "$ch" = 'y' -o "$ch" = 'Y' ]
do
        clear
        echo "Menu"
        echo "1. Absolute mode"
        echo "2. Symbolic mode"
        echo "3. Exit"
        echo "Enter your choice"
        read choice
        case $choice in
        1)
                echo "Absolute mode"
                echo "Enter the file name"
                read f1
                echo "Enter the file permission"
                read str
                echo "Permission before changing"
                ls -l $f1
                chmod $str $f1
                echo "Permission after changing"
                ls -l $f1
                ;;
        2)
               echo "Symbolic mode"
               echo "Enter file name"
               read f2
               echo "Permission before changing"
               ls -l $f2
               echo "Enter the category u/g/o"
               read category
               echo "Enter the operator +/-"
               read operator
               echo "Enter the mode r/w/x"
               read mode
               chmod $category$operator$mode $f2
               echo "Permission after changing"
               ls -l $f2
               ;;
       3)
               exit
               ;;
       *)
               echo "Invalid input"
               ;;
       esac
       echo "Do you want to continue... y/n"
       read ch
       clear
done

Aim

Writing a shell script in Linux/Unix to simulate the behavior of fork and exec system calls by creating a child process.
exp11.sh
#!/bin/sh
echo "Parent Process ID: $$"

echo "Creating child process..."

(
echo "Child process executing date command"
exec date
)

echo "Parent process continues."

Sample output

output
$ sh exp11.sh
Parent Process ID: 2337
Creating child process...
Child process executing date command
Tue Nov 3 23:46:38 IST 2026
Parent process continues.
( ... ) starts a child process (the fork); exec date replaces that child with the date command (the exec). The PID and the date will be different on your computer. From the sh-tested record: the $BASHPID line of the official sheet was removed because sh does not support it.

Aim

Writing a Shell Script Program to check if a file is readable, writable, or executable in Linux/Unix.
exp12.sh
#!/bin/sh
echo "Enter the file name:"
read filename

# Check if file exists
if [ ! -e "$filename" ]; then
   echo "File does not exist."
   exit 1
fi

# Check permissions
[ -r "$filename" ] && echo "The file is readable." || echo "The file is not readable."
[ -w "$filename" ] && echo "The file is writable." || echo "The file is not writable."
[ -x "$filename" ] && echo "The file is executable." || echo "The file is not executable."

Sample output

output
$ sh exp12.sh
Enter the file name:
demo.txt
The file is readable.
The file is writable.
The file is executable.

Missing file run:
Enter the file name:
nosuch.txt
File does not exist.
The lines printed depend on your file. Run as your normal user, not root: root can access almost everything, which hides the permission effect. A missing file exits with status 1 on purpose.
